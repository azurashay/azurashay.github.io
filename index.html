01 / Problem

Sales weren't coming back

The platform captured rich account engagement - but reps rarely returned to read it. We needed a view so easy to scan that a rep could grasp an account's momentum in seconds.

02 / Insight

Engagement is a two-way story

What matters isn't a pile of views - it's the interplay between the rep's outreach and the lead's response. Both belong on the same timeline.

03 / Decision

One glanceable timeline

Per person, over time - red dots for the rep's activity, blue for the lead's engagement, each sized by how strong the touch was. One look shows who's warming up and where to push.

04 / Outcome

A reason to log back in

Reps got a living, at-a-glance picture of every account - a reason to open the platform and act, instead of letting engagement data go unread. Sales logins rose by ~15%.

02 / Folloze AI Agent Conversational UI

Folloze Campaign Agent

A conversational AI agent that turns a few plain sentences about a product into a personalized B2B campaign - guiding the user one step at a time and assembling everything needed to launch.

folloze · campaign-agent / build
The full flow. Describe a product, answer a few guided questions, and the agent assembles a ready-to-launch board - Product, Audience, Message and Goal filling in live.
Loading states · live
Building your page. A four-stage sequence - thinking, diagnostics, generating structure, designing - plays while the agent assembles the board.
Thinking. A lightweight inline indicator for the shorter waits between steps.
01 / Problem

The blank-canvas tax

Starting an ABM campaign meant facing a dozen decisions at once - product, audience, message, goal. High effort up front, slow to start, easy to abandon.

02 / Insight

Talking beats form-filling

People describe their product in plain words far more easily than they fill structured fields. Let a conversation do the structuring for them.

03 / Decision

An agent that asks, then assembles

A chat that asks one question at a time and mirrors progress in a live panel - Product, Audience, Message, Goal - ending in a ready-to-launch board.

04 / Outcome

From idea to board in minutes

By turning a blank canvas into a guided conversation, the agent lifted campaign-page creation by ~28% and cut the time to prepare a page from hours to minutes.

Under the hood · prompt engineering

The simple chat hides two layers of prompt engineering - one that gives every building block meaning, and one that assembles them into a page.

01 · Section prompts

Every block knows itself

Each section carries its own visual content and its goal, so the agent understands what a block contains and what it is there to achieve.

02 · Page-builder agent

Assembles the page

A second prompt takes everything the user gave - product, audience, message, goal - and decides which sections to pull and how to compose them into a finished page.

03 / Folloze AI Ad generation

Folloze - AI LinkedIn
ad generator

Turn a campaign into a set of ready-to-run LinkedIn ads - generated on-brand, then refined by AI: rewrite the copy, restyle the image, all in one place.

Generated ads · LinkedIn
folloze · campaigns / linkedin-ads
Ready-to-run ads. From a single campaign, a set of on-brand LinkedIn ad creatives is generated - sized, written, and ready to download.
Edit any ad. Clicking Edit opens a panel - rewrite the LinkedIn headline and subtitle with AI (improve, lengthen, shorten), or chat to restyle the image itself.
01 / Problem

Creative is the bottleneck

Every campaign needs ad creative, and producing on-brand variations by hand is slow - a queue that holds launches back.

02 / Insight

The campaign already holds the brief

Message, audience and brand all live in the campaign. The ad doesn't need to be built from scratch - it can be generated from what's already there.

03 / Decision

Generate, then refine in place

Auto-produce a set of on-brand LinkedIn ads, each editable on the spot - AI rewrites the headline and subtitle, and a chat restyles the image.

04 / Outcome

Campaign-ready creative in minutes

Marketers go from a finished campaign to a full set of LinkedIn-ready ads in minutes, without waiting on a design queue.

Under the hood · prompt engineering

Each ad set comes from a two-step prompt pipeline - the whole board distilled into one brief, then fanned out across four distinct design languages.

01 · Summarize the board

Everything, condensed

All the campaign details on the board are collected and compressed into a single tight summary the model can reason over.

02 · Distill into a prompt

One brief, four styles

The summary becomes a focused generation prompt - copy derived strictly from the campaign, styling pulled from the brand's own CSS - that renders four templates, each a different visual language.

template_01 · modern-typography-first.prompt1 of 4
ROLE
You are a senior brand & performance designer producing one modern B2B LinkedIn feed ad.
Single objective: stop the scroll and earn a reply. Judge every decision against it.

INPUTS  — authoritative; treat as ground truth, never override
  campaign_details : {{campaign_details}}
  brand_css        : {{css_styles}}
  logo             : {{logo_file}}

GROUNDING CONTRACT
- Every word, number, and claim must trace back to campaign_details. If it isn't there, it doesn't exist.
- Never fabricate metrics, customers, benefits, proof, or outcomes.
- Missing detail → omit it. Do not hedge, generalize, or fill the gap.

CREATIVE DIRECTION  — typography-first
The words are the design; no illustration, iconography, or stock imagery.
Register: sharp, minimal, confident, contemporary, premium.
The strategy is clarity — no cleverness, metaphor, or wordplay.

HEADLINE  — required
- 4–7 words · legible in <1s · maximum scale · heaviest available weight.
- Framing: pain, risk, or uncomfortable truth. Direct question or statement. Concrete nouns only.
- Reference patterns (adapt, don't copy): "Still doing [manual process]?" · "Your [core asset] is exposed." · "[Key task] shouldn't be this hard."

SUBLINE  — optional, ≤1 line
Factual context grounded in campaign_details. No persuasion, promises, or outcome language.

TYPOGRAPHY SYSTEM
Headline ≥60% of canvas · tight leading · deliberate line breaks · vertical stack.
Type family resolved from brand_css. Build hierarchy through weight (Black / Bold / Medium) and size contrast.
Accent 1–2 words with brand primary-3. No text shadows, outlines, or gradients.

LAYOUT
1:1 · left-aligned or vertically stacked · strict grid · generous negative space. Nothing competes with the headline.

COLOR & CONTRAST
High contrast. Solid or ultra-subtle gradient background. Palette strictly from brand_css; primary-3 reserved for emphasis. No textures, patterns, or graphic elements.

BRANDING
Place {{logo_file}} small and quiet, top-left or bottom-left. No container behind it. Preserve legibility.

CTA  — optional
Small, neutral, conversation-led — include only if it earns its place: "Let's talk." · "Worth a look?"

GUARDRAILS  — never produce
Paragraphs · explanations · unsupported claims · slogans · "AI-powered" · "next-gen" · "revolutionary" · icons · illustrations · decorative graphics.

SELF-CHECK  — verify silently before responding
  ✓ every claim maps to campaign_details      ✓ color & type only from brand_css
  ✓ text contrast ≥ WCAG AA (4.5:1)           ✓ headline 4–7 words, reads in <1s

OUTPUT CONTRACT  — return valid JSON only, no prose
{
  "headline":       string,       // 4–7 words
  "subline":        string | null, // ≤1 line, factual
  "cta":            string | null,
  "emphasis_words": string[],      // 1–2 words rendered in primary-3
  "rationale":      string         // one sentence linking copy to campaign_details
}
One of four templates. Each defines a different visual language - typography-first, image-led, editorial, bold-color - so every campaign renders in four on-brand directions.
04 / Dell EMC Enterprise SaaS Information architecture

Dell EMC XtremIO - Dashboard redesign

A storage-management dashboard that showed every metric to every user with equal weight. I turned a wall of data into three focused views - one per audience.

xtremio · dashboard / performance
Performance view. IOPS, latency, bandwidth and capacity at a glance - built for the operators who live here every day.
xtremio · data-protection / overview
Data Protection view. RPO compliance, protection sessions and the replication topology - the backup team's priorities on a screen of their own.
01 / Problem

One screen, everyone, everything

The original dashboard pushed health, performance, capacity, top volumes and weekly patterns at the user with equal priority - high cognitive load and no clear hierarchy.

02 / Insight

It wasn't one audience - it was three

Through user shadowing I found three distinct groups. Each cared most about a single metric, with everything else as secondary context.

03 / Decision

Three tabs, three priorities

I split the dashboard into three focused tabs, each owning one group's key metric - while keeping a glanceable summary up top, so no one felt they were missing the wider picture.

04 / Outcome

Calmer, more confident usage

Users reported a noticeably better experience. Most settled into the tab relevant to them and navigated outward from there - exactly the behaviour the structure was designed to create.
